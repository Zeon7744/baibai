## 自动化工作流

### 1. Update Content (自动触发)
- **触发条件**: 提交到短剧项目目录或README更新
- **功能**: 
  - 扫描短剧项目目录
  - 更新README中的项目列表
  - 获取爱发电赞助者名单
  - 自动提交并推送

### 2. Publish to GitHub Pages
- **触发条件**: 编剧工坊.html 更新
- **功能**: 部署编剧工坊到 https://zeon7744.github.io/baibai/

### 3. Sync to Gitee
- **触发条件**: GitHub push 或手动触发
- **功能**: 同步代码到 Gitee 镜像

## 使用方法

### 创作新短剧

1. 打开 [编剧工坊](https://zeon7744.github.io/baibai/)
2. 选择创作模式：
   - **要素生成**：输入故事要素，自动生成剧本
   - **小说改编**：上传小说文本，自动改编为短剧格式
3. 导出剧本文件
4. 创建目录：`短剧项目/{剧名}/`
5. 保存剧本：`{剧名}_完整剧本.md`
6. 提交到GitHub：自动触发同步

### 发布流程

```bash
# 克隆仓库
git clone https://github.com/Zeon7744/baibai.git

# 添加新剧本
mkdir 短剧项目/新剧名
cp 剧本.md 短剧项目/新剧名/新剧名_完整剧本.md

# 提交推送
git add .
git commit -m "feat: add 新剧名"
git push
```

## 创作规范

### 格式要求
- ✅ 标题：第X集：集名
- ✅ 结尾：第X集完
- ✅ 对话：≤15字/句
- ✅ 每集：≥500字，≥3爽点+1甜点
- ❌ 禁止：耀/曜、【】括号

### 文件命名
- 剧本：`{剧名}_完整剧本.md`
- 角色表：`{剧名}_角色表.md`（可选）
- 分集大纲：`{剧名}_分集大纲.md`（可选）
