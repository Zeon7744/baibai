## 简介

baibai 是一个 MCP (Model Context Protocol) 工具库，提供实用的开发工具。

## 功能特性

- 代码格式校验器
- 数据分析助手
- README 自动生成器
- JSON/YAML 格式检查
- MCP Server 集成

## 快速开始

```bash
git clone https://github.com/Zeon7744/baibai.git
cd baibai
```
