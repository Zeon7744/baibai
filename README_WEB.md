# Baibai 金融分析器 - Web 使用指南

## 快速开始

### 方式一：本地打开（推荐）

1. 克隆仓库
```bash
git clone https://github.com/Zeon7744/baibai.git
cd baibai
```

2. 打开页面
```bash
open web/index.html
# 或双击 web/index.html
```

3. 在搜索框输入股票代码，点击"分析"

### 方式二：部署到 GitHub Pages

```bash
# 在仓库设置中启用 Pages
# Source 选择 main 分支 /web 文件夹
```

访问地址：`https://用户名.github.io/baibai/web/`

## 功能说明

### 技术分析
- **价格走势** - 实时价格曲线
- **RSI** - 相对强弱指标（超买>70，超卖<30）
- **MACD** - 指数平滑异同移动平均线
- **成交量** - 交易活跃度

### MLP 预测
- **分类准确率** - 涨跌预测准确比例
- **回归 RMSE** - 预测误差
- **预期收益** - 未来5日预期收益率
- **特征重要性** - 各指标对预测的贡献度

### 投资建议
综合技术指标和 ML 预测，给出：
- 操作建议：买入 / 卖出 / 观望
- 风险等级：低 / 中等 / 高
- 具体信号解读
